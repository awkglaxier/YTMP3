# AwokenYT — โหลด mp3 จากลิ้ง YouTube หลายลิ้งพร้อมกัน

เว็บแอปส่วนตัวสำหรับใช้บนเครื่องตัวเอง: วางลิ้ง YouTube หลายลิ้งในกล่องเดียว (บรรทัดละลิ้ง หรือวางรวมกันก็ได้ ระบบหยิบลิ้งออกมาให้เอง) แล้วกดปุ่มเดียว โหลดเป็นไฟล์ mp3 **พร้อมกันหลายลิ้ง** ตามจำนวนที่ตั้งไว้

```
AwokenYTWeb/
├── server.js        ← ตัว server จัดคิวเรียก yt-dlp (zero-dependency, ไม่ต้อง npm install)
├── config.json      ← ค่าคอนฟิก (port, จำนวนโหลดพร้อมกัน, โฟลเดอร์ปลายทาง ฯลฯ)
├── server.bat       ← ดับเบิลคลิกเพื่อเปิด server + เปิดหน้าเว็บทันที (Windows)
├── downloads/       ← ไฟล์ mp3 ที่โหลดเสร็จ (สร้างให้อัตโนมัติ)
└── web/
    ├── index.html   ← หน้าเว็บหลัก (เปิดตรงๆ ก็ได้ หรือผ่าน server ก็ได้)
    ├── style.css
    └── app.js
```

## สิ่งที่ต้องมีในเครื่อง

| โปรแกรม | ใช้ทำอะไร | วิธีติดตั้ง (Windows) |
|---|---|---|
| **Node.js** | รัน server | โหลดจาก https://nodejs.org (ติดตั้งครั้งเดียว) |
| **yt-dlp** | โหลดเสียงจาก YouTube | `winget install yt-dlp` หรือโหลด `yt-dlp.exe` จาก https://github.com/yt-dlp/yt-dlp/releases แล้ววางไว้ที่ `bin/yt-dlp.exe` ในโฟลเดอร์นี้ หรือที่ใดก็ได้ที่อยู่ใน PATH |
| **ffmpeg** | แปลงเสียงเป็น mp3 (yt-dlp ต้องใช้) | `winget install ffmpeg` หรือโหลดจาก https://www.gyan.dev/ffmpeg/builds/ แล้วเพิ่มลง PATH |

ตรวจว่าพร้อมหรือยัง: เปิด cmd แล้วพิมพ์ `yt-dlp --version` กับ `ffmpeg -version` — ถ้าขึ้นเวอร์ชันแปลว่าใช้ได้ (หน้าเว็บก็จะขึ้น badge เขียวให้เห็น)

## วิธีใช้

1. ดับเบิลคลิก **server.bat** → จะเปิดหน้าเว็บ `http://127.0.0.1:5577` ให้อัตโนมัติ
   - หรือเปิดไฟล์ `web/index.html` ตรงๆ ก็ได้ (ต้องเปิด server ไว้ด้วยเสมอ)
2. วางลิ้ง YouTube ลงกล่อง — ใส่กี่ลิ้งก็ได้, บรรทัดละลิ้งหรือวางรวมกันก็ได้
3. กด **เริ่มโหลดทั้งหมด** → ระบบจะโหลดพร้อมกันหลายลิ้งตามค่า `maxConcurrent` (ค่าเริ่มต้น 3) ส่วนที่เหลือเข้าคิวรออัตโนมัติ
4. ดู % ความคืบหน้า/ความเร็ว/ETA ของแต่ละลิ้งแบบเรียลไทม์ กด ❌ เพื่อยกเลิกรายการใดรายการหนึ่งได้
5. ไฟล์ mp3 อยู่ที่โฟลเดอร์ `downloads/` — กดปุ่ม 📂 เปิดโฟลเดอร์ หรือกดปุ่มที่รายการเพื่อชี้ไปที่ไฟล์นั้นใน Explorer

## ปรับแต่ง (config.json)

| คีย์ | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|
| `port` | `5577` | พอร์ทของ server (ถ้าเปลี่ยน ให้แก้ `API_BASE` ใน `web/app.js` ด้วย) |
| `maxConcurrent` | `3` | **จำนวนลิ้งที่โหลดพร้อมกันสูงสุด** — มากไปอาจโดน YouTube จำกัดอัตรา แนะนำ 2-4 |
| `downloadDir` | `downloads` | โฟลเดอร์ปลายทาง (สัมพัทธ์กับโฟลเดอร์โปรแกรม หรือระบุ absolute path ก็ได้) |
| `audioQuality` | `"0"` | คุณภาพ mp3 (`0` = ดีที่สุด ≈ 245-320 kbps, `5` = ~130 kbps) |
| `filenameTemplate` | `%(title)s.%(ext)s` | รูปแบบชื่อไฟล์ (ดู template อื่นใน docs ของ yt-dlp) |
| `embedMetadata` | `true` | ฝัง metadata ลงไฟล์ mp3 |
| `ytDlpPath` | `yt-dlp.exe` | ตำแหน่ง yt-dlp (ถ้าไม่อยู่ใน PATH ให้ระบุ full path) |
| `ffmpegPath` | `""` | ตำแหน่ง ffmpeg (เว้นว่างถ้าอยู่ใน PATH แล้ว) |

## API (สำหรับผู้อยากต่อยอด)

- `GET /api/health` — สถานะ yt-dlp/ffmpeg + โฟลเดอร์ปลายทาง
- `GET /api/status` — รายการงานทั้งหมด (สถานะ, %, ความเร็ว)
- `POST /api/download` — body `{ "links": ["url1", "url2"] }` เพิ่มลิ้งเข้าคิว
- `POST /api/cancel` — body `{ "id": "..." }` ยกเลิกรายการเดียว
- `POST /api/cancel-all` — ยกเลิกทุกรายการ
- `POST /api/clear` — ล้างรายการที่เสร็จ/ผิดพลาดแล้ว
- `POST /api/open-folder` — เปิดโฟลเดอร์ปลายทาง
- `POST /api/reveal` — body `{ "id": "..." }` เปิด Explorer ชี้ที่ไฟล์นั้น

## หมายเหตุ

- ใช้ส่วนตัวบนเครื่องตัวเอง — server ผูกกับ `127.0.0.1` เท่านั้น เครื่องอื่นเข้าไม่ได้
- โหลดวีดีโอที่มีข้อจำกัดอายุ/ลิขสิทธิ์อาจผิดพลาด — ข้อความ error จะแสดงที่รายการนั้นๆ
- ถ้า yt-dlp โหลดไม่ได้ทั้งหมด ลองอัปเดต: `yt-dlp -U` (YouTube เปลี่ยนบ่อย ควรใช้เวอร์ชันใหม่ล่าสุด)
